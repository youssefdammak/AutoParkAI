# AutoParkAI

Welcome to **AutoParkAI** — an AI-powered smart parking system that automatically **detects license plates**, **tracks parking availability**, and provides a **web interface** for real-time monitoring and management.

---


## Features

* **License Plate Detection**: Automatically detects car plates in real-time using YOLOv8.
* **Parking Management**: Tracks availability and stores entries in a database.
* **Web Dashboard**: Monitor parking in real-time via a React interface.
* **Training Pipeline**: Includes scripts to train YOLOv8 on custom datasets.

## Technologies Used

* **Python**, **YOLOv8** – License plate detection and training
* **React**, **HTML**, **CSS**, **JavaScript** – Frontend interfaces
* **Node.js / Express** – Backend server and API integration
* **MySQL / CSV** – Data storage for vehicle entries

---

## Getting Started

### Prerequisites

* [Python 3.x](https://www.python.org/)
* [Node.js](https://nodejs.org/)
* [npm](https://www.npmjs.com/)

---

## Usage

1. Place a car image or video in the input folder.
2. Run the detection script to see plates detected in real-time.
3. Access the dashboard to monitor parking availability and vehicle entries.
4. Use the web UI for a lightweight view of parking stats.
